# 📊 Monthly & Yearly Reporting Management System

A comprehensive web-based reporting and office management system developed using **Python Flask**, **MySQL**, **HTML**, **CSS**, **Bootstrap**, and **JavaScript**. The system is designed to manage organizational records, monthly and yearly reports, procurement requests, complaints, repair & maintenance, software requests, meeting records, budgets, and other administrative operations through a centralized dashboard.

# ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/AbdulRaziqG0812/monthly-yearly-repost-software.git
```

### 2. Navigate to Project Directory

```bash
cd monthly-yearly-repost-software
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

If a `requirements.txt` file is not available, install Flask manually:

```bash
pip install flask
```

### 4. Configure Database

- Create a MySQL database.
- Import the SQL files from the **SQL** folder.
- Update the database configuration inside `app.py`.

### 5. Run the Application

```bash
python app.py
```

Open your browser:

```
http://127.0.0.1:5000/
```
